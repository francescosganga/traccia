Do / Don't

Do

  • One red button per view: the primary action, or Record/Stop.
  • Use the segmented control for every enumerated setting, everywhere.
  • Show shortcuts as ⌘⇧R via formatShortcut().
  • Give status cards an icon tile and a border in their hue.
  • Space with the 4 pt scale and the .mt-* utilities.

Don't

  • Fill a destructive button with red — red text on a ghost button instead.
  • Use red for focus, links or selection.
  • Put red buttons in lists (downloads, permissions).
  • Use emoji as icons; use <Icon>.
  • Reference a primitive (--n-700, --red-500) from a component.
